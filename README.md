# Supply Chain Simulation Game

Live multiplayer supply-chain game for the Operations Club MBA event.
Built by Brahmajit Saha.

Stack: Next.js (Vercel) + Supabase (Postgres, Auth, Realtime).

## Environment variables (set these in Vercel)
- `NEXT_PUBLIC_SUPABASE_URL` — your Supabase project URL
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` — your Supabase publishable key

This is the Phase 1–2 starter: a landing page that verifies the database
connection. Game logic is added in later phases.
